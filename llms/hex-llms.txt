# Hex

> Hex is an AI-powered analytics platform combining agentic notebooks, interactive data apps, and conversational self-serve analytics. The Hex External API (bearer-token, base https://app.hex.tech/api/v1) runs and schedules projects, manages projects/collections/groups/cells/data-connections, ingests semantic models, drives AI agent Threads, and administers users. Rate limit: 60 requests/minute per user; max 25 concurrent kernels. Cursor pagination via pagination.after. No idempotency-key contract.
